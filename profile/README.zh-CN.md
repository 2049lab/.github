## 项目介绍 · PersonOS

**[PersonOS](https://pypi.org/project/personos/)** 是我们的多模态长期记忆 Python 框架。它把视频、图片和对话整理为情景记忆，将观察结果关联到人物，并在回答问题时返回支持答案的证据。

面向开发**机器人、智能眼镜和桌面 Agent** 的开发者。

```bash
pip install personos
personos doctor
```

基础功能使用本地 SQLite 存储，需要配置模型服务。视频处理和人物识别需要额外依赖及模型配置；安装步骤和示例见 [PyPI 包文档](https://pypi.org/project/personos/)。

Python 包已在 PyPI 发布，源码仓库目前需要访问权限。
